# C-PROGRAMS
C Programs by Sheikh Shaheem
This repository contains a collection of C programs created by Sheikh Shaheem, a student of Computer Science and Engineering (CSE) at Islamic University of Science and Technology (IUST).

📚 About
These programs are written as part of academic coursework, practice exercises, and personal exploration of the C programming language. The aim is to strengthen foundational programming skills and problem-solving using C.

🔧 Topics Covered
Some of the areas covered include:

Basic syntax and I/O

Control structures (if-else, loops)

Functions

Arrays and strings

Pointers

Structures and unions

File handling


Command-line arguments

Data structures (linked lists, stacks, queues – if included)
